About My Secret Manager

This is a simple web application designed to securely store and manage your personal or application secrets.

It was built as a learning project to demonstrate:

  • Flask web framework
  • User authentication with Flask-Login and Flask-Bcrypt
  • Database management with Flask-SQLAlchemy and Flask-Migrate
  • Encryption of sensitive data with the cryptography library
  • Basic web server deployment with Apache and mod_wsgi
